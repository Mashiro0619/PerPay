# 首页网站概览金额卡片验收

验收日期：2026-10-10（北京时间）。范围为首页各网站概览及其统计接口。

## 展示与数据

卡片保留网站名称、区间实收及 4px 对比横条，只显示暂停接单和非零当前待办。名称最多两行，重名编号独立显示；移除每卡日期、确认笔数、待付款数量和独立页脚。普通演示卡片高度约 114–116px，长重名卡片自然增高至约 148–149px。

横条以全部未删除网站的本期最高实收为满格，包括暂停接单的网站，不受搜索和分页影响。所有已加载卡片共享最近成功响应的标尺；全站金额为零时不填充横条。

`GET /api/admin/v1/sites/overview` 保留原网站汇总字段，增加顶层 `period: { from, to }` 和 `max_confirmed_amount_cents`，撤回本轮尚未发布的每站 `daily`。日期按上海自然日、首尾包含；实收沿用确认事件口径，不扣退款和费用。查询固定为 5 条，无数据库迁移。

周期切换重新请求，保持每分钟刷新和每页 10 个网站。只合并相同 `period` 的页面；跨日追加（包括空页）重新读取第一页。首次失败显示重试，追加失败保留已有卡片与标尺。

## 浏览器验收

使用 Windows Chromium 156 和构建后的只读演示，实际检查 390/768/1024/1440/1920px × 明暗主题 × 收缩/全屏布局，共 20 组；页面和金额均无横向溢出，横条高度均为 4px。按容器宽度显示 1/2/3/4 列，1920px 全屏布局显示 4 列。

- 网站名、金额和横条区域均可点击进入对应网站后台，并携带 `range`。
- Tab/Shift+Tab、可见焦点和 Enter 导航通过；Ctrl 点击及中键实际打开新标签页，原页面保持不变。
- 在触摸设备模拟下，从卡片滑动使页面滚动且不触发导航，轻触卡片可正常导航。
- 用临时浏览器响应替换检查长重名、暂停与大金额，在五种宽度及明暗主题下均完整显示金额，独立编号保持可见。未修改演示数据库。
- 用临时响应模拟首次及追加读取失败：首次不显示零金额卡片；追加失败保留 4 张已有卡片与原比例，重试恢复 8 张且移除错误提示。
- 实际 API 请求 `range=30&limit=1` 返回全站最大实收 1714807 分，当前页网站实收 149017 分，确认标尺不从当前页推算；响应无 `daily`。
