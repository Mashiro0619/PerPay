## 总览样板

### 变化

- 在管理端外壳下定义候选视觉变量，统一总览数字层级、卡片留白、表面层次和悬停反馈；公开页面继续使用既有主题与布局。
- 使用单一直接依赖 `motion@14.7.1`，在周期、指标、图表类型和视图 Tabs 中移动选中指示器；Base UI 继续负责控件语义和键盘交互。
- 图形局部使用 `motion/mini` 做 180ms、0.95 至 1 的透明度过渡；文字、金额、坐标轴、操作控件和每日数据不变淡，不插值财务数字。
- 不延迟保留旧内容，不使用 `AnimatePresence`；减少动态效果或页面隐藏时，装饰切为静态，业务控件和焦点不变。
- 图表初载和普通数据刷新不播放入场；连续切换取消旧动画，不排队。

### 复核与修正

首版对完整 CardContent 做淡入，在动画中降低了辅助文字对比度；已收窄到实际图形。减少动态效果模式直接使用 Base UI 原生选中背景，避免无必要的装饰覆盖；正常模式另验证指示器实际运动和颜色。

构建检查未在公开收银台运行代码或服务端渲染产物发现 Motion 引用。当前候选构建 gzip 合计增加：后台 46,000 字节，收银台共享 CSS 990 字节，收银台服务端渲染产物 0 字节。最终以收尾构建记录为准。

## 侧栏反馈

- 在各菜单组内复用 Motion 选中指示，移动左侧 2px 细线；保留 Nova 选中背景、图标、文字与运行提醒。
- 仅侧栏导航关闭全页 View Transition，避免页面快照遮盖实时指示器；正文链接保留原有转场。
- 侧栏尺寸由已有 CSS 过渡控制，采用公共节奏；减少动态效果与页面隐藏时只停止装饰，不替换业务链接。
- 64 项相关组件测试、后台和 UI 类型检查、后台构建通过。
- 桌面实际纵向轨迹为 70.39 → 78.13 → 88.28 → 106.39，约 215ms 收敛。细线右边界 18px、图标左边界 24px、文字左边界 48px，无遮挡；折叠图标模式同样通过。
- 手机抽屉关闭与焦点归还、动态减少动画、路由和 `aria-current`、既有图标侧栏回归通过。桌面首次固定时刻采样过近终点，改为从路由提交起逐帧采样后通过，产品代码未因此修改。
- 证据：`.ui-audit/runs/frontend-polish-sidebar/`、`.ui-audit/runs/frontend-polish-sidebar-corrected/`；组件检查日志：`.ui-audit/frontend-polish/sidebar-motion-unit.log`。
