## 总览样板

### 变化

- 在管理端外壳下定义候选视觉变量，统一总览数字层级、卡片留白、表面层次和悬停反馈；公开页面继续使用既有主题与布局。
- 使用单一直接依赖 `motion@14.7.1`，在周期、指标、图表类型和视图 Tabs 中移动选中指示器；Base UI 继续负责控件语义和键盘交互。
- 图形局部使用 `motion/mini` 做 180ms、0.95 至 1 的透明度过渡；文字、金额、坐标轴、操作控件和每日数据不变淡，不插值财务数字。
- 不延迟保留旧内容，不使用 `AnimatePresence`；减少动态效果或页面隐藏时，装饰切为静态，业务控件和焦点不变。
- 图表初载和普通数据刷新不播放入场；连续切换取消旧动画，不排队。

### 复核与修正

首版对完整 CardContent 做淡入，在动画中降低了辅助文字对比度；已收窄到实际图形。减少动态效果模式直接使用 Base UI 原生选中背景，避免无必要的装饰覆盖；正常模式另验证指示器实际运动和颜色。

构建检查未在公开收银台运行代码或服务端渲染产物发现 Motion 引用。当前候选构建 gzip 合计增加：后台 46,000 字节，收银台共享 CSS 990 字节，收银台服务端渲染产物 0 字节。最终以收尾构建记录为准。

- 仅非敏感列表补充信息使用该过渡，没有修改全局 Collapsible 或账号密钥显示机制。关闭时先归还内部焦点，立即设为 `inert` 和 `aria-hidden`，由 Base UI 在过渡完成后卸载。
- 保持记录实例、真实金额、刷新后的展开状态与焦点。面板左右各预留 4px 焦点绘制空间，并抵消外侧间距，字段列的位置不变。
- 相关 60 项组件测试通过；焦点余量修正后，列表原语与行导航 24 项复测、后台类型检查、后台与收银台构建通过。

- 新增 3 项浏览器检查与既有 320px／100%、200% 字号两项回归通过；保留长商品名的两行摘要，并验证详情能完整读取，64 字符商户编号与展开字段不裁切。焦点链接采用明确标注的合成探针，当前真实补充字段仍为日期和文本。

## 验收工具修正

完整检查发现同一测试文件中的模拟计时轮询会影响后续表单聚焦：两个字段已经被正确标记为错误，但 jsdom 的待执行动画帧没有在恢复真实计时前排空。修正测试清理顺序为先卸载、执行待处理计时任务、再恢复真实计时；原字段、焦点、草稿和路由断言全部保留。该文件 12 项复测通过，未修改向导或表单生产逻辑。

全路由审计还发现原对比度辅助测量仅接受纯文字选中项，无法解析图表类型按钮的图标与标签。现限定支持一个不可交互 SVG 和一个纯文字标签，验证实际文字绘制、背景、几何与命中，拒绝额外文本、文字填充色覆盖和 SVG 越界绘制。真实按钮测量及半透明标签等反例通过；独立 Chromium 复核中，三类漏检均保持未解决，三个正常 Lucide 图标均通过。axe 原始未确定项继续保留，不按规则名称统一豁免。证据：`.ui-audit/runs/frontend-polish-contrast-guards/`。
