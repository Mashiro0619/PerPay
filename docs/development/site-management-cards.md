# 网站经营卡片与入口调整验收

验收日期：2026-10-10（北京时间）。延续首页金额卡片样式，扩展网站管理页面。

## 当前行为

- 首页在概览请求成功、没有下一页、日期区间一致且只有一个网站时隐藏“各网站概览”。查询和每分钟刷新继续工作；出现第二个网站后恢复显示。加载、失败和未完成分页不当作单站结果，零网站空态保留。
- 管理网站页面始终显示网站卡片，包括只有一个网站的情况。卡片展示网站名称、接单与通知状态、区间实收、统一标尺横条、确认笔数、当前待付款、当前待办，以及“网站设置”和“进入后台”。名称最多两行，重名编号单独显示，非零待办沿用琥珀色提示。
- 管理页默认近 30 天，可切换 7／30／90 天，`range` 写入地址且保留 `selected_site`。每页 30 个网站，复用 `GET /api/admin/v1/sites/overview`，不逐站查询统计；与首页共用分页、每分钟刷新、跨日重置和横条组件，缓存按周期及页大小区分。
- 侧栏“管理网站”从业务网站展开菜单移至“全局管理”首项，随后是共享账本、运行状态。业务网站切换器与设置位置保留；管理网站、创建网站、默认模板页面都正确高亮管理入口。导航记忆不改变全局数据范围。

## 检查结果

- `npm run typecheck:admin`、`npm run build:admin`、`git diff --check` 通过。
- 首页及相关概览回归 42 项、管理卡片及网站配置回归 45 项、侧栏及工作空间相关回归 149 项通过。
- 全量前端首次运行 1370 项通过，1 项旧模板恢复夹具因未提供新的概览端点而失败。补齐模板恢复、侧栏和引导中的旧响应夹具后，模板恢复 14 项及侧栏／引导／可用性 71 项定向重跑通过。失败用例已修复，未重复运行无关文件。
- 本轮未改服务器统计或接口契约，未重复后端全量检查。统计口径及后端验证延续[金额卡片验收](site-overview-amount-cards.md)。

## 浏览器验收

使用构建后的本地只读演示与 Windows Chromium 156：

- 管理页在 390／768／1024／1440／1920px、明暗主题、收缩／全屏共 20 组组合下，页面和金额均无横向溢出，两项卡片操作均可访问。常规卡片高度约 263–266px，1920px 全屏为 4 列。
- 用临时概览响应模拟单站：主页概览区块消失，管理页保留一张卡片及设置／创建入口；未改演示数据库。
- 7／90／30 天切换实际发送对应日期范围与 `limit=30` 的批量请求。进入后台携带周期；返回管理页保留所选网站的导航记忆，请求仍是全局统计；网站设置入口正确进入相应网站。
- 手机导航抽屉中的“全局管理 → 管理网站”可点击，跳转后抽屉关闭。
- 在 390／1024px 检查长重名、暂停、接近安全整数上限的金额及大数量：名称最多两行，编号可见，金额与数量无溢出。
- 页面控制台仅有只读演示按设计返回的更新检查 503，没有新增 JavaScript 或 CSP 错误。
