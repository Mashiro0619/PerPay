# 版本说明

这里按版本说明新增了什么、哪些操作需要调整，以及怎样升级数据库。下载安装包与镜像请前往 [GitHub Releases](https://github.com/Mashiro0619/PerPay/releases)，各版本的主要变化见[变更日志](../../CHANGELOG.md)。

## 当前开发版本

| 版本 | 重点 | 数据库结构版本（schema） |
| --- | --- | --- |
| [1.0.0](v1.0.0.md) | 完整收款流程、多网站与多账号、原生与易支付接入、备份恢复 | 44 |

1.0.0 正在准备发布。RC4 以来的功能、修复及后续改动已归并到版本说明，包含初始化令牌默认开启、重复收款码检查、操作结果核对、审计与备份调整，以及后台和收银台改进。之后新增的改动记录在[待发布变更](unreleased.md)。
