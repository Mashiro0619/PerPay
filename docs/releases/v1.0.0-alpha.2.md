# PerPay 1.0.0-alpha.2

相较于 alpha.1，本版增加登录设备管理、初始化令牌、手动查账和更新设置，并完善备份恢复及通知接入。

## 主要更新

- **登录设备**：查看 IP 和设备信息，让某个设备退出登录，或退出其他登录设备；升级前的登录状态继续有效。
- **手动查账**：在运行状态发起查账，查看等待和执行进度。查询尚未完成时，重复请求加入同一个任务；查账仍遵守请求间隔、频率限制和失败后的重试等待时间。
- **更新设置**：支持稳定版和包含预发布两个通道，默认包含预发布。自动检查默认开启，每 6 小时在页面可见且联网时检查；偏好保存在当前浏览器，也可手动检查。
- **首次初始化**：创建管理员需填写启动日志中的一次性令牌，服务重启后令牌更换。
- **收银台与导航**：支持复制准确应付金额，持续提醒按识别尾数付款；窗口高度较小时，侧栏可单独滚动。
- **备份恢复**：在线备份期间固定所读取的数据，形成一致的数据库副本。原库损坏时，可保留损坏文件并从有效备份恢复；补充主密钥与备份的异地加密保存步骤。
- **通知与接入资料**：完善 HTTP/TLS 失败后的重试，提供同时验证新旧通知密钥的示例，并补充快速指南、签名向量和错误说明。
- **网站与兼容性**：批量忽略提醒时，在同一数据库事务中确认记录属于所选网站；缺少必填内容时，在对应输入项显示错误。后台入口统一为 `/admin/`，并改善旧浏览器兼容。
- **查询与数据说明**：改进查找可人工关联的订单或流水的查询，补充数据保留规则及第三方许可声明。

原有稳定通道选择与自动检查开关保留；旧的“跟随当前版本”按新默认值处理。完整记录见[变更日志](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-alpha.2/CHANGELOG.md)。

## 升级与恢复

本版的数据库结构版本（schema）为 **36**，兼容范围为 **24—36**。

1. 备份数据库，单独保存原主密钥 `PERPAY_MASTER_KEY`。
2. 将三个服务统一设为 `ghcr.io/mashiro0619/perpay:1.0.0-alpha.2`，按[固定版本升级步骤](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-alpha.2/docs/maintenance.md#固定版本与回滚)操作。
3. 启动后检查原网站、查账和备份任务；新实例初始化使用本轮启动日志中的令牌。

回退到 alpha.1 或更早版本需恢复升级前备份与原主密钥。预发布固定标签不会更新稳定版 `latest`。
