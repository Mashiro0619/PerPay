# PerPay 1.0.0-alpha.2

这是 1.0 系列的第二个预发布版本。相较于 1.0.0-alpha.1，本版增加登录设备管理、一次性初始化令牌、手动查账及更新检查设置，改善收银台和后台使用体验，并完善备份恢复及通知接入。

Alpha 版本用于新功能试用和升级验证，已有生产收款建议继续使用稳定版。源码版本号与说明文件存在不代表已创建发布标签或镜像，部署前请确认对应的 GitHub Release 和镜像已经可用。

## 主要更新

- **登录设备管理**：在系统设置中查看登录 IP 和设备信息，逐项退出会话，或退出其他登录设备。升级前已有的会话继续保留。
- **手动查账**：在运行状态直接发起查账，查看等待、执行中及本轮结果；重复请求共用现有任务，继续遵守最小间隔、限流和失败退避。页面刷新后可继续查看进度，查账完成不代表某笔订单已付款。
- **更新检查**：支持“仅稳定版”和“包含预发布版”两个通道，默认包含预发布版。自动检查默认开启，登录后及页面可见联网时每 6 小时检查；也可手动检查。偏好保存在当前浏览器，旧的“跟随当前版本”选择按新默认值处理，已有稳定版选择和自动检查开关保持不变。控件对齐排列，仅在发现更新、检查中或检查失败时显示状态，不自动下载或安装。
- **后台导航**：短视口下的侧栏内容可独立滚动，页脚链接保持完整可见。
- **初始化与收银台**：首次初始化需填写启动日志中的一次性令牌；收银台可复制准确应付金额，并持续提示按识别尾数付款。
- **备份恢复**：固定快照在线备份，损坏主库可显式隔离后恢复；日志提供安全错误原因，并新增主密钥与备份的异地加密保存说明。
- **通知接入**：完善 HTTP/TLS 失败重试、双通知密钥示例、快速指南和可校验签名向量。
- **网站与兼容性**：批量忽略增加事务内网站校验，网站必填字段显示自定义错误，后台入口统一到 `/admin/`，较旧浏览器不再依赖新的数组排序 API。
- **性能与数据说明**：优化人工关联候选查询，修复后台基准脚本，增加数据保留说明及第三方许可证声明。

完整改动见[变更日志](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-alpha.2/CHANGELOG.md)。

## 升级与恢复

本版将数据库升级至 schema 36，运行兼容范围为 24—36。**升级前先备份数据库，并单独保存原 `PERPAY_MASTER_KEY`。回退到 1.0.0-alpha.1 或更早版本，必须恢复升级前备份及原主密钥，不能直接用旧程序打开升级后的数据库。**

预发布镜像固定为 `ghcr.io/mashiro0619/perpay:1.0.0-alpha.2`。`app`、`backup`、`maintenance` 三个服务须使用同一版本；本版不会更新稳定版 `latest`。

完整升级步骤、数据库兼容范围及恢复方法见[维护说明](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-alpha.2/docs/maintenance.md#固定版本与回滚)。
