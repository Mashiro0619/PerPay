# PerPay 发布准备

当前开发版本为 `1.0.0-rc.5`，数据库结构 44。完整变更与升级要求见 [RC5 发布说明](v1.0.0-rc.5.md)。

## 待发布改动

- 调整错误说明文字颜色，浅色与深色主题均满足普通文字对比度要求。

- 稳定版发布恢复校验当前完整作业集合，保留全部 UI 分片成功的要求。

- 自动备份在等待期间及时读取新间隔和保留策略，调整频率无需重启备份进程。

- 确认金额按每次确认的历史快照汇总，争议订单重新确认不再改写原日期的统计。

- 新网站正确区分生成与轮换密钥，创建后直接进入接入配置；支付宝向导展示具体缺项和下一步。
- 订单首屏区分待付款、过期和关闭；列表默认显示商户订单号，CSV 可选择日期并包含收款账号及金额单位。
- 争议订单可在核对流水并填写理由后重新确认，保留历史证据；退款后的提醒可逐条忽略。
- 通知重发后直接查看新结果，历史投递可跳转最新记录；待处理列表优先展示需要人工处理的事项。
- 空总览引导首次收款，手机收银台补齐保存二维码后的支付宝付款步骤。
- 备份摘要展示任务与可恢复副本，补齐全新服务器恢复步骤；发布模板与镜像固定同一版本。
- 审计先展示失败原因，查账诊断直接展示账号与任务状态，无业务通知轮次按小时汇总。
- 空结果和重复流水的成功单页采集副本保留 7 天并分批回收，控制长期运行的数据增长。
- 备份压实空闲页，减少重复完整性扫描；新增数据库空间诊断和停服压实命令。
- 无变化的健康查账和对账按小时汇总；三个 Compose 服务共用一个镜像配置，首次反代部署按网络创建、代理配置、启动顺序进行。
- 修复列表清除条件后的草稿残留和窄屏搜索控件遮挡，精简重复说明。
- 修正前端开发启动命令，增加源码、数据流与验证入口导航。

前版易支付及网站接入变更见 [RC4 发布说明](v1.0.0-rc.4.md)。发布状态以 GitHub Release 和对应固定版本镜像为准；新版本按[发布模板](TEMPLATE.md)整理。
