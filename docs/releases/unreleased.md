# PerPay 发布准备

## 待发布改动

- 易支付密钥在页面隐藏、离开或展示满 60 秒后自动清除，并忽略已失效的查看、导出响应。
- 易支付设置、密钥查看/轮换和配置导出的审计记录使用中文动作、网站对象及密钥用途名称。
- 支付宝查账、连接检查和密钥验证改用官方 Node.js SDK 签名与验签，PerPay 适配层保存原始账单证据并处理超时、取消及错误分类。
- 固定 SDK 及修复版传输依赖，新增可重复运行的 SDK 契约验证。
- 支持易支付 V1/V2 下单、查询、商户统计、付款通知和同步返回，沿用现有收款与对账流程。
- 网站接入助手提供三种协议的完整配置下载，易支付密钥按网站加密保存并支持轮换。
- 新网站默认开启 V1/V2 并自动生成密钥，启动时补齐未初始化网站，保留已保存的开关和凭据。
- Node Demo 支持三协议及隔离数据目录，PHP、Go SDK 与 New API 充值和订阅完成隔离联调。
- 数据库升级至结构 42，新增稳定 PID、凭据历史、兼容订单和 GET 通知证据。升级前自动创建备份。

当前开发版本为 `1.0.0-rc.4`，完整内容见 [RC4 发布说明](v1.0.0-rc.4.md)。上一发布版本的数据库校验与升级修复见 [RC3 发布说明](v1.0.0-rc.3.md)。发布状态以对应 GitHub Release 和固定版本镜像为准。

下一版本准备发布时建立对应说明并更新本页入口，已发布说明记录其对应版本的行为与兼容范围。[发布模板](TEMPLATE.md)
