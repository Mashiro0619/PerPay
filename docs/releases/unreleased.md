# PerPay 未发布改动

**这版改了什么：** 新增全局支付宝流水查询、归组详情及关联订单导航。<br>
**要不要升：** 当前改动尚未发布，部署以对应 Release 和镜像实际可用为前提。<br>
**升级前做什么：** 按[维护说明](../maintenance.md#固定版本与回滚)核对版本、备份和回滚条件。

当前开发目标为 `1.0.0`，多网站支持、破坏性变更及 schema 35 升级要求见 [1.0.0 版本说明](v1.0.0.md)。迁移 35 仅增加流水查询索引，不改写历史财务事实。

流水页面展示当前环境已采集并规范化的记录，默认全部日期。相同内容跨来源去重，差异版本和多个生效关联保留异常及凭据；生产与沙箱隔离。查询与刷新只读本地账本，不触发支付宝采集。

此文件不表示该版本已经发布；发布状态请以实际 GitHub Release 和镜像为准。

完整回归与发布前验收仍以开发分支实际检查结果为准。

后续发布说明必须使用[发布模板](TEMPLATE.md)，升级步骤和 schema 说明统一链接维护文档。
