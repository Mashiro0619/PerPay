# PerPay 未发布改动

当前源码已准备 [1.0.0-rc.1](v1.0.0-rc.1.md)，包含支付宝多账号、网站指定／随机／加权收款、账号独立查账和三步首次设置。接入统一使用支付宝平台已上线的正式应用；旧沙箱接入及其自动对账、通知处理停用，历史记录和归属保留。待处理列表补全订单、网站、金额和异常信息；概览控件适配窄屏，图表类型记忆在当前浏览器。

数据库升级至 schema 38，保留删除账号的历史关联以保证重启和恢复完整性；已发布的 1.0.0-alpha.2 仍以 schema 36 为上限。原使用沙箱的实例需添加已上线应用的正式账号并调整网站的新订单分配。

版本号和说明文件不代表已经公开发布。部署前请确认目标版本的 GitHub Release 和镜像已经可用；升级与回退要求见[维护说明](../maintenance.md#固定版本与回滚)。
