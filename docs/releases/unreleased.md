# PerPay 未发布改动

基于 `0.3.1` 的后续源码，尚未发布镜像；不能将已发布 v0.3.1 视为包含这些改动。

- 安全设置增加可选管理员 IPv4 / IPv6 / CIDR 白名单，默认关闭，保存立即生效，强制允许当前来源；不限制支付接口。
- 提供独立离线关闭命令，保留规则、密码、会话和支付数据。
- 最新数据库 schema 为 **32**，运行兼容范围为 **24—32**。从 schema 23 升级执行迁移 24—32，从 schema 26 升级执行迁移 27—32。
- 不能将 schema 32 数据库交给已发布 v0.3.1（最大 31）或更旧镜像打开；升级前备份，维护镜像必须匹配。
