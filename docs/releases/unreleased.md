# 待发布变更

当前源码版本为 `1.0.0`，尚未发布。数据库结构版本（schema）为 44，兼容范围为 24—44；最新公开版本为 [1.0.0-rc.4](v1.0.0-rc.4.md)。

## 待发布改动

RC4 发布后的功能、修复和升级步骤已汇总到 [1.0.0 说明](v1.0.0.md)，之后新增的改动在这里继续记录。从 RC4 的结构版本 42 升级会执行迁移 43、44；已经使用结构版本 44 的开发版本无需再次迁移数据库。

新增条目要写清楚用户会看到什么变化、需要改哪些配置，以及是否需要迁移数据。发布时，把条目移入对应版本文件，按[发布模板](TEMPLATE.md)补齐升级步骤，再更新[版本索引](README.md)与[变更日志](../../CHANGELOG.md)。

- 支付宝账号禁止重复配置同一收款码，修改协议、域名大小写或附带参数也不会绕过检查。更换应用请编辑原账号；已有重复配置按[多账号说明](../multi-site.md#网站收款账号)清理。
- 运行状态复用未改变备份的校验结果，应用启动及每小时在后台执行完整校验。概览显示最近内容校验时间，新副本或文件变化会立即重新校验。
- 普通查询和匿名错误请求按分钟汇总；未关联核心审计的查询和匿名请求每分钟最多接收 600 条待写入记录，最多保留 20,000 条。审计采集状态显示超出预算的数量、最近时间和原因，付款与配置等核心审计继续逐条保留。
- 首次创建管理员默认要求初始化令牌，从最新启动日志读取后填写。已创建管理员的实例照常登录；显式配置 `PERPAY_SETUP_TOKEN_ENABLED=false` 仍然有效，本地预览已单独关闭令牌。
- 易支付设置和密钥操作等待超过 20 秒后可关闭窗口，并重新读取配置核对结果。轮换超时不会自动重试，迟到响应不会覆盖后来打开的界面。
- 后台统一使用“支付宝账号 → 业务网站 → 试收款”配置流程，移除旧单账号向导和全局密钥设置。旧设置地址会跳转到对应的账号或网站入口。
- 测试收款界面在打开时加载，减少后台初次进入需要下载的代码；加载期间可以取消并再次打开。
- 收银台单独打包所需样式，付款页面下载的 CSS 从约 237 kB 减少到 59 kB，继续与后台共用主题和基础控件。
- 成功的备份健康检查只返回状态，避免每轮生成一个长期保留的审计来源；检查失败仍记录原因和结果。
- 撤销登录会话成功后立即关闭确认窗口并显示结果，会话列表在后台刷新，读取延迟不会继续锁住窗口。
- 账号、网站、默认模板和管理员白名单的编辑操作等待超过 20 秒后可以关闭；写入超时或响应丢失时保留输入和原版本，重新读取核对后再继续。密码修改结果不明确时提供重新登录入口。
- 首次打开总览时，收款趋势的标题、筛选、统计和下方内容保持原位，绘图区按需加载。
- 列表搜索提示缩短为「输入关键词，回车搜索」，窄屏使用「关键词」，避免文字在搜索框内被截断。
- 支付宝账号配置完成后，各标签页不再重复显示收款状态横幅，收款状态和查看入口集中到「使用情况」。缺少配置或启用后无法收款时仍显示处理提示。
- 后台用「查看范围」切换网站，用「网站管理」维护网站。页名统一显示一次，桌面页面操作放到标题旁；未知地址的正文和标签页标题一致。
- 手机总览先显示待处理和最近订单，网站概览默认显示四项，可展开查看全部；每日数据使用独立滚动区域。趋势汇总金额随宽度调整字号，完整保留小数位，今日指标的统计口径可点击查看。
- 列表日期筛选集中显示范围和北京时间，显示列名称按单列排列；通知投递历史说明当次失败类型。网站配置分类在窄屏使用选择器，冲突核对操作纵向排列，单行密钥使用紧凑查看窗口。
- 已配置收款码显示摘要和更换入口，最近连接检查集中到使用情况；未启用且没有历史文件的备份摘要集中显示任务和策略。窄屏配置向导显示当前步骤，设置卡片标题与操作分行。
- 收银台将查询付款状态与扫码操作放在同一栏，桌面状态放进订单资料标题区；放大二维码在大字号和短横屏下为码图留足空间。
