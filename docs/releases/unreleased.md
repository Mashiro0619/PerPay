# PerPay 未发布改动

基于 `0.3.1` 的后续源码，尚未发布镜像；不能将已发布 v0.3.1 视为包含这些改动。

- 安全设置增加可选管理员 IPv4 / IPv6 / CIDR 白名单，默认关闭，保存立即生效，强制允许当前来源；不限制支付接口。
- 提供独立离线关闭命令，保留规则、密码、会话和支付数据。
- 最新数据库 schema 为 **33**，运行兼容范围为 **24—33**。从 schema 23 升级执行迁移 24—33，从 schema 26 升级执行迁移 27—33。
- 不能将 schema 33 数据库交给已发布 v0.3.1（最大 31）或更旧镜像打开；升级前备份，维护镜像必须匹配。

- 增加可配置的采集最小间隔，范围 5～3600 秒且不大于活跃间隔；旧设置请求保留现值。统一调度合并请求，等待时间与退避跨重启保留，分页续采不受普通轮次间隔阻断。

- 收银台自动刷新不再驱动手动按钮转圈；手动核实通过受控采集和对账跟踪真实进度，失败和超时明确反馈，保留静默自动更新。
