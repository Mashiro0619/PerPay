# PerPay 0.3.0-alpha.1

## 预发布提示

0.3.0 的首个 Alpha 基于 0.2.2 重新整理后台和收银台，增加查询和人工核账操作，适合在独立实例试用。安装此预发布版需使用固定镜像标签；稳定版 `latest` 仍指向原版本。

## 更新内容

### 管理后台与收银台

- 后台统一使用 shadcn/ui，整理侧栏、设置、表格和弹窗，支持明暗主题、手机与键盘操作。
- 收款概览支持面积图、柱状图和折线图，完整显示金额；每日数据可直接查看并分页。
- 订单详情集中展示确认收款所用的记录、关联流水、异常及通知；每次通知的发送结果可分页查看，原始报文可按需展开。
- 收银台支持桌面与手机布局、二维码放大与保存，显示付款、暂停收款和订单失效状态。
- 实例可控制收银台商品名显示和默认图表样式，订单与通知数据保留原值。

### 查询与人工核账

- 订单、通知、关联、冲突、异常和待处理列表支持搜索、排序、游标分页和选择显示哪些列；搜索在服务器上执行，覆盖全部记录。
- 人工关联会推荐可能匹配的记录，也支持搜索。可以先选订单再选流水、先选流水再选订单，或分两步选择。
- 推荐结果优先考虑金额相同、付款时间与订单有效期重叠的记录。确认前重新读取订单和流水，由管理员核对、填写理由并确认。
- 冲突详情逐字段展示已有值、传入值和差异，保留原金额、精确时间、长编号与备注。
- 提醒可按筛选跨页忽略，并查看已忽略记录、单条恢复或继续中断操作。

### 运行提示与操作恢复

- 运行故障与业务待处理分别展示；暂停收款、数据库异常和状态未知继续提示。
- 初始化、表单保存、测试收款、退款标记和人工关联失败后可继续处理；无法确定操作是否成功时，保留相关记录、填写内容和操作编号，供核查或重试。
- 新实例默认每 60 秒进行常规查账，每 8 秒进行活跃查账，查账结果有效时限为 120 秒；旧实例保留已保存配置。

### 预发布版本与更新

- 按 SemVer 比较 Alpha、Beta、RC 和正式版，如 `rc.2 < rc.10 < 同版本正式版`。
- 正式版只提醒正式版更新，预发布版同时提醒正式版和预发布版更新。后台显示提醒后，由部署者手动安装。
- 预发布 Compose 附件固定到对应版本，后续升级需更新三个服务的镜像标签。

## 兼容性与数据安全

本版的数据库结构版本（schema）为 **26**，兼容范围为 **24—26**。从 0.2.2 升级执行迁移 24—26，增加显示设置和查询索引，保留订单金额、流水证据、财务记录及原配置。

新增用于查找可关联订单或流水的管理员接口，以及后台列表的查询参数；业务网站继续按原有协议下单和接收通知。系统推荐的关联记录仍需管理员确认，忽略提醒后原冲突仍需处理；退款标记只记录管理员在支付宝完成的退款。

## 试用与升级

1. 保存数据库备份、原主密钥和部署配置，在独立实例验证升级。
2. 将 `app`、`backup`、`maintenance` 统一设为 `ghcr.io/mashiro0619/perpay:0.3.0-alpha.1`，保留自己的域名、代理与数据卷配置。
3. 在原部署目录执行：

   ```sh
   docker compose pull
   docker compose up -d
   ```

4. 核对原账号、配置、历史订单及运行状态，开始收款前完成查账和自动确认检查。

回退到 0.2.2 需恢复该版本兼容的备份和原主密钥。升级后已有交易时，先保留当前完整数据，避免旧备份覆盖新增记录。
