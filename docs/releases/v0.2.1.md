# PerPay 0.2.1

本版增加官方更新提醒，并简化首次配置、测试收款和密钥操作。

## 更新内容

- 管理员登录后自动检查官方更新，也可在运行状态手动检查。需要更新时，由部署者手动安装。
- 首次配置收起高级参数，减少重复字段和说明。
- 测试收款页改为居中展示，创建订单前仍会检查金额和账号是否已准备好收款。
- 密钥操作的提示更简洁。页面显示的密钥仍会在限定时间后清除，更换密钥前需要确认。
- 整理开发说明和支付宝配置教程。

## 升级

数据库结构版本（schema）仍为 **19**，从 0.2.0 升级后继续使用原配置。

1. 备份数据库，另存 `perpay-secrets` 主密钥卷。
2. 将 `app`、`backup`、`maintenance` 统一设为 `ghcr.io/mashiro0619/perpay:0.2.1`。
3. 在原部署目录执行：

   ```sh
   docker compose pull
   docker compose up -d
   ```
