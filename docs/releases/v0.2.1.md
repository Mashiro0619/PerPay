## 升级

先备份数据库和 `perpay-secrets` 主密钥卷，保留原数据卷。

如果固定了镜像版本，先将 `app`、`backup`、`maintenance` 的镜像统一改为 `ghcr.io/mashiro0619/perpay:0.2.1`。然后在原部署目录执行：

```sh
docker compose pull
docker compose up -d
```

本版数据库结构仍为 19，从 0.2.0 升级无需重新配置。
