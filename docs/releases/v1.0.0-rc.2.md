# PerPay 1.0.0-rc.2

相较于 1.0.0-rc.1，本版增加全局审计日志，并调整后台详情、设置和手机列表的操作方式。管理员可以在保留列表位置的详情弹层中核对订单、收款账号、流水和通知，追溯操作来源及字段变化；部署者需要按新的保留规则管理数据库、备份与导出文件。

RC 版本面向受控试用与升级验证。源码版本号和说明文件不代表镜像已经发布，部署前请确认对应 GitHub Release 和固定版本镜像已经可用。

## 主要更新

- **详情与设置**：订单、通知、流水、对账、审计和网站概况使用统一详情弹层，桌面居中、手机全屏，关闭后保留父页筛选和位置。网站与账号编辑的分组共享草稿，设置摘要直接显示收款分配和白名单规则；对账详情刷新同步更新关联证据。
- **多账号核对**：新账号先创建再继续配置，未完成时可先保存；同名收款账号用 App ID 或编号区分。人工关联最终确认分别显示订单和流水所属账号，金额不同会提示核对；中文输入法确认组词不会提前搜索，再次创建测试订单后焦点返回金额。
- **待处理提醒**：修复按关键词或网站筛选批量忽略后，合法记录被完整性校验误判、导致备份或重启失败的问题。已有操作记录可直接核对，无需迁移或重写审计。
- **收银台恢复与布局**：二维码加载失败后可重新加载；长金额和短横屏下调整金额与放大二维码的布局，保留关闭操作空间。
- **手机列表与趋势**：网站列表保留进入后台及设置入口，通知明确区分业务事件和投递结果，流水保留关联订单及账号身份；最近订单的商品名与状态分行显示。收款趋势增加“金额与订单”组合视图，金额和笔数使用各自刻度，窄屏和放大文字下的操作可换行。
- **运行状态与更新**：服务读取失败和断网提示集中呈现；侧栏显示暂停接单、运行告警与更新状态，支持键盘查看说明。更新弹窗在编辑时延后显示，可在运行状态页忽略当前通道的版本提醒、恢复提醒或重新查看更新。
- **审计查询**：在全局“审计日志”中按来源、类别、动作、结果、操作者、历史网站、IP、日期和关键词查询。桌面表格和手机摘要列表使用同一筛选与分页，详情可查看本次请求或任务关联的核心记录。
- **操作追溯**：关键订单状态、自动／人工收款确认、撤销关联及管理操作保留核心审计；幂等重试不重复生成核心事实。新记录显示当时的来源 IP、设备及普通字段变更前后值，秘密只显示已变更；历史缺失信息保持未记录。
- **运行活动**：关键行为、失败和任务结果逐条记录；普通成功查询按分钟汇总次数、首次／最后时间和耗时，静态资源不记录。查询按来源限制读取量后合并，筛选目录增量更新。备份与维护进程通过备份目录交接事件，恢复、删除和清理记录保留经过验证的操作目标。
- **数据保留**：核心审计及上下文持续保留，接口与任务活动保留 30 天；核心事实不会随活动清理删除。已检测来源缺口持久保存，重启后继续提示；交接文件按批次清理，异常退出遗留来源也执行保留策略。
- **CSV 导出**：按当前筛选导出最多 366 天内的 10,000 条记录，超限须缩小范围。导出使用固定读取快照及公式转义；生成成功会留下审计，下载后的文件由下载者保管。

## 接入调整

新增管理员审计列表、详情、筛选元数据和导出接口，均要求管理员会话；导出另需同源与 CSRF 校验。接口查询全局记录，网站筛选不改变权限。业务下单、请求签名与通知协议保持现有契约，参见 [OpenAPI](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-rc.2/openapi.yaml) 与[审计维护说明](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-rc.2/docs/maintenance.md#审计日志与采集状态)。

管理员原始流水详情新增可选的收款账号 ID 和名称，历史归属不可用时返回空值；旧客户端无需修改，历史缺失信息不推断补填。

## 升级与恢复

本版使用 schema 39，运行兼容范围为 24—39。迁移保留原有审计事件和哈希，增加上下文、活动与采集凭据；旧记录的来源和字段变化不回填。

升级前使用旧版本完成备份，单独保存原主密钥 `PERPAY_MASTER_KEY`，然后停止应用与自动备份，将 `app`、`backup`、`maintenance` 同时切换到本版。完成迁移后检查审计采集状态、后台任务及备份恢复。已有的 `PERPAY_BACKUP_DIR/perpay-activity/v1` 事件文件也应保管，其中可能包含尚未采集的维护记录。

1.0.0-rc.1 的结构上限仍为 38。回退到 rc.1 或更早版本必须使用对应升级前备份和原主密钥；升级后产生的新记录不能通过直接换旧镜像保留。

预发布镜像固定为 `ghcr.io/mashiro0619/perpay:1.0.0-rc.2`，不覆盖稳定版 `latest`，也不会自动跟随后续 RC。原多账号与正式支付宝应用接入要求继续适用。

完整升级步骤、数据库兼容范围及恢复方法见[维护说明](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-rc.2/docs/maintenance.md#固定版本与回滚)。
