# PerPay 1.0.0-rc.2

相较于 1.0.0-rc.1，本版补齐管理操作、关键订单与资金状态的永久审计上下文。关键事实与审计在同一事务写入，幂等重试不重复生成核心记录。非敏感字段保留变更前后值，秘密只保存变更标记；历史缺失信息保持未记录。

RC 版本面向受控试用与升级验证。源码版本号和说明文件不代表镜像已经发布，部署前请确认对应 GitHub Release 和固定版本镜像已经可用。

## 升级与恢复

本版使用 schema 39，运行兼容范围为 24—39。迁移保留原有审计事件和哈希，增加上下文、活动与采集凭据结构；旧记录的来源和字段变化不回填。

升级前使用旧版本完成备份，单独保存原主密钥 `PERPAY_MASTER_KEY`，然后停止应用与自动备份，将 `app`、`backup`、`maintenance` 同时切换到本版。1.0.0-rc.1 的结构上限仍为 38，回退须恢复对应升级前备份和原主密钥。

预发布镜像固定为 `ghcr.io/mashiro0619/perpay:1.0.0-rc.2`，不覆盖稳定版 `latest`，也不会自动跟随后续 RC。原多账号与正式支付宝应用接入要求继续适用。

完整升级步骤、数据库兼容范围及恢复方法见[维护说明](https://github.com/Mashiro0619/PerPay/blob/v1.0.0-rc.2/docs/maintenance.md#固定版本与回滚)。
