# PerPay 0.2.0

本版新增管理后台、首次收款向导和调用端 Demo，可以按步骤配置支付宝、创建订单并查看付款结果。

## 更新内容

- 管理后台提供六步首次收款向导，支持经营码图片识别、配置检查和密钥管理。
- 收银台适配手机、深浅色主题，支持下载 PNG 二维码。
- 首页显示影响收款的故障；填写配置出错时指出需要修改的字段，从详情返回列表时保留筛选和分页。
- 新增停服重设管理员密码的命令，保留订单和密钥。
- 提供 `demo.zip`：接收付款通知并验证签名后更新付款状态，也可手动查单。
- 更新依赖并修复已知安全问题。

## 升级

数据库结构版本（schema）仍为 **19**，与 0.1.0 相同，升级后继续使用原有配置。

1. 备份数据库，另存 `perpay-secrets` 主密钥卷。
2. 将 `app`、`backup`、`maintenance` 的镜像统一设为 `ghcr.io/mashiro0619/perpay:0.2.0`，在原部署目录执行：

   ```sh
   docker compose pull
   docker compose up -d
   ```

3. 访问 `/admin`，核对原配置和订单。使用旧版 Demo 时补齐回调地址和通知签名密钥；旧订单继续使用原回调配置。
