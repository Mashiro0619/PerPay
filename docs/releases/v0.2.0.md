## 更新内容

- 新增管理后台与六步首次收款向导，支持经营码图片识别、配置检查和密钥管理。
- 重做收银台，支持手机布局、深浅色主题和 PNG 二维码下载。
- 首页显示收款故障，配置错误定位到具体字段，返回列表保留筛选和分页。
- 增加停服后的管理员密码恢复命令，保留订单与密钥。
- 提供调用端 `demo.zip`，默认通过验签回调确认付款，手动查单作补偿。
- 更新依赖，修复已知安全漏洞。

## 升级

先备份数据库和 `perpay-secrets` 主密钥卷，再在原部署目录执行：

```sh
docker compose pull
docker compose up -d
```

保留原数据卷；本版数据库结构仍为 19，与 0.1.0 相同。更新后访问 `/admin`；已有配置直接复用，不需要重新初始化。使用旧版 Demo 的用户需补齐回调地址和通知签名密钥，旧订单仍保留原回调配置。
