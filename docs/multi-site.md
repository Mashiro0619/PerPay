# 多网站与多账号管理

单个 PerPay 实例可同时接入多个业务网站并绑定多个支付宝收款账号。各网站的订单、密钥与回调通知互相隔离。

> 相关文档：[文档目录](README.md) · [支付宝配置指南](alipay-setup.md) · [易支付接入](epay-integration.md) · [原生 API 快速接入](integration-quickstart.md)

---

<a id="配置归属"></a>

## 1. 配置作用域：全局与单站

后台顶部切换器用于在 **全部网站**（全局视图）与 **单个业务网站**（单站视图）之间切换：

| 配置项 | 归属层级 | 说明 |
| --- | --- | --- |
| 支付宝账号、应用密钥与收款码 | 全局账号池 | 独立维护，可供多个业务网站共享绑定 |
| 查账间隔、查账延迟与有效时限 | 全局统一 | 全实例共用策略，各支付宝账号独立调度 |
| 管理员密码、IP 白名单、备份与系统名称 | 全局统一 | 在「全部网站 → 系统设置」中管理 |
| 网站接入凭据（客户端 ID、API/通知密钥、易支付 PID/密钥） | 单站独立 | 轮换单站密钥不影响其他网站 |
| 订单与收银台规则（接单开关、账号分配、加价、冷却、展示名称与帮助链接） | 单站独立 | 在对应网站的「网站设置」中管理 |
| 通知开关、通知/返回来源域名与重试策略 | 单站独立 | 各站独立回调与重试 |

> **说明**：「网站管理」中的 **默认设置模板** 仅作为后续新建网站的初始值，修改模板不会覆盖既有网站的配置。

<a id="创建与接入"></a>

## 2. 创建网站与网站标识

在 **全局管理 → 业务网站** 新建站点并绑定收款账号，随后在对应网站的 **接入与通知** 中配置通知来源并获取接入凭据。

每个网站存在两个不同的标识符：

| 名称 | 特性 | 用途 |
| --- | --- | --- |
| 稳定网站编号（内部 `site_id` / 管理路径 `:clientId`） | 创建后不可变更 | 后台 URL 路径、内部订单与通知归属、易支付固定 PID 绑定 |
| 客户端 ID（`api_client_id` / `X-PerPay-Client-Id`） | 支持更换（3–64 位字母数字及 `._-`） | 原生 API 认证请求头与签名原文 |

- 保留词 `default`、`new`、`defaults`、`overview`（不区分大小写）不可用作客户端 ID。
- 已使用过的客户端 ID 会永久保留占位，更换或删除网站后不会再分配给其他网站。
- 更换客户端 ID 后业务后端需同步更新请求头；历史订单、通知记录、API/通知密钥及易支付 PID 不受影响。

## 3. 多支付宝账号分流规则

在 **网站设置 → 收款设置** 中可为单个网站绑定多个支付宝账号（上限 100 个），支持三种分配策略：

| 分配模式 | 调度策略 | 适用场景 |
| --- | --- | --- |
| 固定账号（`FIXED`） | 仅使用指定的单个账号；该账号不可用时下单失败 | 专号专用 |
| 随机分配（`RANDOM`） | 在已选中且当前可用的账号中等概率随机选取 | 多账号均衡分摊 |
| 按权重分配（`WEIGHTED`） | 按正整数权重概率分配（如 `3:1` 对应 75% / 25%） | 主备或按比例分流 |

**分流与对账约束**：

- **自动跳过不可用账号**：随机与加权模式下，配置未完成、已暂停、查账失败或应付金额槽位已满的账号会被自动跳过。
- **金额冷却按收款账号共享**：多个网站共用同一支付宝账号时，该账号的应付金额占用与复用冷却由这些网站共享；不同支付宝账号之间互不影响。
- **避免重复建号**：同一实际支付宝账户仅应对应一条账号记录；更换查账应用时直接编辑原账号，不要重复新建记录上传相同收款码。
- **删除限制**：已产生订单或流水的支付宝账号不允许删除，仅可暂停接收新订单。

<a id="生命周期与通知"></a>

## 4. 配置变更与暂停对既有订单的影响

订单创建后即锁定所属收款账号、应付金额、收银台有效期与收款码，后续站点配置变更的影响范围如下：

| 操作 | 对新订单的影响 | 对既有订单的影响 |
| --- | --- | --- |
| 暂停网站接单 | 拒绝创建新订单（返回 `503`） | 查单、关闭、收款确认与通知照常执行（同参数幂等重试返回原订单） |
| 关闭网站通知 | 不再发起新通知投递 | 已发出的当前尝试结束后停止；重新开启后继续 |
| 修改通知来源域名 | 新订单校验新域名 | 旧订单重试与重发前同样按新域名校验，不匹配则失败 |
| 修改返回来源域名 | 新订单校验新域名 | 旧订单保留创建时保存的返回地址 |
| 修改收银台名称、商品名显隐或帮助链接 | 生效 | 旧收银台展示外观同步更新，金额与收款码不变 |
| 轮换 API 密钥 | 须使用新密钥 | 旧密钥立即失效 |
| 轮换通知密钥 | 新通知与重试使用新密钥 | 在途请求可能仍使用旧密钥，业务端建议短暂兼容新旧密钥 |
| 删除网站 | — | 仅从未产生订单、事件与通知的空网站允许删除 |

> **说明**：通知队列按网站轮询调度；若某一网站的回调接口频繁超时，可能拖慢其他网站的通知排队速度，建议及时修复或暂时关闭该站通知。

<a id="管理接口的网站范围"></a>

## 5. 多网站管理 API 速查

以下管理接口均需管理员登录会话、JSON 请求体、同源及 CSRF 校验；写操作须携带最新 `revision`（版本冲突返回 `409`），完整 Schema 见 [openapi.yaml](../openapi.yaml)：

| 接口 | 用途 |
| --- | --- |
| `GET / POST /api/admin/v1/sites` | 查询列表或创建网站（创建须携带 `operation_id`、`configuration` 与可选 `client_id`） |
| `GET / PUT / DELETE /api/admin/v1/sites/:clientId` | 读取、更新或删除网站（`:clientId` 始终传入稳定网站编号） |
| `POST /api/admin/v1/sites/:clientId/actions/change-client-id` | 更换公开客户端 ID |
| `POST /api/admin/v1/sites/:clientId/secrets/{api_secret,webhook_secret}/actions/{rotate,view}` | 轮换或查看原生密钥 |
| `GET / PUT /api/admin/v1/settings/site-defaults` | 读取或保存新建网站的默认策略模板 |
| `GET / POST / PUT / DELETE /api/admin/v1/alipay-accounts[/:accountId]` | 支付宝账号管理；`/:accountId/check` 执行连通性测试 |
| `GET /api/admin/v1/sites/overview` | 分页查询各网站统计概览 |

**路径隔离规则**：

- 订单、通知、待处理、测试收款与财务操作既可通过全局接口访问，也可通过 `/api/admin/v1/sites/:clientId/...` 限定在单站范围内（路径已指定网站时，查询参数与请求体不得重复传入 `api_client_id`）。
- 涉及跨站共享流水冲突的财务操作，在单站路径下会返回 `409 / site_scope_conflict`，须改用全局对账接口处理。
